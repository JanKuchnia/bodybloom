## 4. Gaps BODY BLOOM can take

1. **Combination offer.** No competitor found offers training + physio + massage together. Single-service sites can't cross-sell.
2. **Transparent pricing and schedule as real text.** Competitors hide prices in images, Facebook posts or "call to book".
3. **MultiSport page.** Nobody in the SERP checks targets "MultiSport Myślenice" explicitly.
4. **Gift vouchers.** Only Yasumi has a visible voucher path. Seasonal demand (Christmas, Dzień Kobiet, Dzień Matki) is easy to capture.
5. **Community events as content.** Baby Trenują has an events page; others don't. BODY BLOOM already runs events, so reusing them is cheap.
6. **Physio-led training for beginners** ("trening po kontuzji", "kręgosłup"), a bridge between the two service worlds.

## 5. Where BODY BLOOM is behind

- No website, so currently invisible for non-brand queries.
- Few or no Google reviews versus Baby Trenują's 30+.
- No booking profile on Booksy/Fresha/ZnanyLekarz under its own name (research found none).
- Small social following (471 on Instagram).

## 6. Positioning note vs Baby Trenują

Both speak to women, in a casual tone, from the same street area. If BODY BLOOM is mixed-gender, say so clearly and own "training + physio + massage". If it is women-only, differentiate on the **recovery side**, which Baby Trenują doesn't visibly offer, and on the "zero spiny" tone. Never reference Baby Trenują by name.
